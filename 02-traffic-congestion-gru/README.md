# 02 · 城市交通拥堵 GRU 预测

本科毕业论文核心模型部分：用双源数据预测沈阳市青年大街未来 1 小时的拥堵指数，并和 ARIMA、LSTM、移动平均做横向对比。

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 路况 | 高德地图交通态势 API | 矩形区域实时拥堵指数，按 15 分钟粒度采集 |
| 天气 | Open-Meteo API | 温度、湿度、降水、风速、能见度等 |

- **采集时段**：2026-05-10 ~ 2026-05-20，有效 9 天
- **区域**：核心区 / 北区 / 南区，每区域独立建模
- **数据完整度**：96.7%，缺失部分用线性插值补齐（插值占 2.6%）

`data/` 下是清洗后的训练数据（交通、天气、合并三份）。

## 特征工程（24 维 / 区域）

- **时间周期编码**：小时的 sin/cos、星期的 sin/cos
- **高峰标记**：早晚高峰二元标记
- **天气融合**：温度、湿度、降水、风速等连续变量标准化
- **历史拥堵指数**：滑动窗口内的序列

## 模型结构

```
输入 (36 步 × 24 特征)
  → GRU 层 1（hidden_size=64, dropout=0.2）
  → GRU 层 2（hidden_size=64, dropout=0.2）
  → 全连接 64 → 32 → 2
输出 (未来 12 步 = 1 小时)
```

- **参数量**：45,176
- **滑动窗口**：36 步输入，12 步输出
- **数据切分**：7 : 1.5 : 1.5（时序切分，不打乱）
- **训练**：Adam，初始学习率 0.001；Huber Loss；梯度裁剪 [-1.0, 1.0]，early stopping 10 轮，weight_decay 1e-4

## 结果

**MAPE（越低越好）**

| 区域 | **GRU** | LSTM | ARIMA(5,1,0) | 移动平均 |
|---|---|---|---|---|
| 核心区 | 4.59% | 5.17% | **3.78%** | 6.04% |
| 北区 | **2.29%** | 2.33% | 2.74% | 3.49% |
| 南区 | **3.16%** | 3.59% | 3.54% | 4.49% |

**对应准确率（1 − MAPE）**：核心区 95.41%，北区 97.71%，南区 96.84%

## 结论与局限（说真话）

1. **北区、南区 GRU 最优**，比 ARIMA 分别低 0.45 和 0.38 个百分点。
2. **核心区 GRU 输给了 ARIMA**（4.59% vs 3.78%）。原因是核心区序列规律性强、周期性明显，这类序列正好是 ARIMA 的舒适区；而模式越复杂的区域，GRU 的特征融合能力才体现出价值。
3. **模型选择是场景匹配问题，不是"谁更先进"**。如果只追单指标最优，核心区就该上 ARIMA；如果要一套模型覆盖多区域、少调参，GRU 的泛化性更强。
4. **数据量是硬限制**：9 天数据只能覆盖一个完整周周期，训不出季节层面的规律。数据量经验——低于 1000 条基本靠猜，2000–3000 条能学到日周期，8000 条以上才有完整周周期。

第 3 条写进了论文第 6 章局限性，没有藏。
