# 01 · 淘宝用户行为分析

把 1.0 亿条用户行为日志拆成能支撑业务决策的指标、漏斗和用户分层。

## 数据

- **来源**：阿里巴巴天池「淘宝用户行为数据集」（UserBehavior）
- **规模**：100,150,807 行 × 5 列（user_id / item_id / category_id / behavior_type / timestamp）
- **时间跨度**：2017-11-25 ~ 2017-12-03，共 9 天
- **用户量**：50,000 人（抽样）
- **行为类型**：pv 浏览 / fav 收藏 / cart 加购 / buy 购买

仓库里的 `data/user_behavior_sample.csv` 是 20,000 行样本（1.5 MB），足够跑通全部代码；完整数据集请自行从天池下载。完整数据集请从天池自行下载。

## 关键结论

**流量基本盘**

- 总 PV 4,502,223 次，总 UV 50,000 人，人均 PV 90.04 次/人
- 日均 PV 500,247 次，日均 UV 38,777 人

⚠️ **口径坑**：日均 UV 不能用「总 UV ÷ 天数」——那样得到 5,556 人/天，与真实 38,777 差了近 7 倍。必须先按天 groupby 求每日去重用户数，再取均值。

**周期性**

- 工作日平均 PV 473,671 次，周末 533,467 次，周末高出 **12.6%**

**行为构成极度倾斜**

- 点击（pv）占全部行为的 **89.58%**
- 收藏、加购、购买三种深度行为加起来才 10% 出头

**转化漏斗**

- 点击 → 收藏：**3.23%**
- 有点击行为的用户 49,800 人，有加购 37,273 人，有购买 34,021 人
- 缺口最大的一环在「点击→收藏/加购」，也就是**从浏览到产生兴趣**这一步，而不是最后付款

**RFM 分层**

- 有购买行为的用户 34,021 人，按 R/F/M 各五分位打分（qcut + rank 处理重复边界）
- 分层结果中**流失用户 4,764 人，占 14.00%**
