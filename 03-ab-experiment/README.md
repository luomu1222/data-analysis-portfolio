# A/B 实验设计与分析框架

用真实电商行为数据的基线，走完一次 A/B 实验的完整决策链：**样本量设计 → 随机分流 → 主指标检验 → 护栏指标 → 重复窥探风险**。

## 1. 为什么做这个

大多数简历上的「熟悉 A/B 测试」停留在"两比例 z 检验"，缺三件事：

- 不知道**实验前要算样本量**（跑 2 天就看结果，多半是功效不足）
- 不知道**分流要验 SRM**（样本比例失衡说明分流逻辑有问题）
- 不知道**反复看结果是会涨假阳性的**（这是实验平台最贵的坑）

这个项目把这三件事都量化出来。

## 2. 数据

基线不是编的，来自本机跑通的电商数仓（ODS→DWD→DWS→ADS 四层，1.0 亿条行为日志）：

| 指标 | 数值 |
|---|---|
| 9 天平均购买转化率（buy_uv / uv） | **19.26%** |
| 逐日转化率区间 | 17.91% – 20.69% |
| 日均 UV | 774,283 |
| 有行为用户数 | 987,991 |
| 用户层下单次数分布 | 0 单 5,633,064 人 / 1 单 948,157 / 2 单 244,812 / 3 单 79,279 |

> 诚实声明：真实数据里没有实验变量，**策略效应是模拟出来的**；但基线转化率、样本规模、方差、检验方法和决策规则全部按真实口径走。这是"用真数据做方法论验证"，不是"伪造实验结果"。

## 3. 方法

| 环节 | 做法 |
|---|---|
| 样本量 | 两比例功效公式，α=0.05（双侧）、power=0.8 |
| 分流 | 50/50 随机分流，固定种子可复现 |
| SRM 检查 | 卡方（1 自由度）检验实际流量比例是否符合预期 |
| 主指标 | 两比例 z 检验（合并方差）+ Wald 差值置信区间 |
| 护栏指标 | 人均下单次数，Welch t 检验（不假设方差相等） |
| 决策规则 | 主指标显著 **且** 护栏不显著恶化 **且** SRM 通过 → 才放量 |

## 4. 结果

### 样本量表（相对 MDE）

| 相对提升 | 每组所需 | 总计 | 按日均 UV 需 |
|---|---|---|---|
| 2% | 164,894 | 329,788 | 0.47 天 |
| 5% | 26,471 | 52,942 | 0.07 天 |
| 10% | 6,654 | 13,308 | 0.02 天 |
| 15% | 2,973 | 5,946 | 0.01 天 |

**这张表本身就是结论**：日活 77 万的站，检测 5% 的相对提升只要 5.3 万样本；但想检测 2% 的细粒度提升，就得到 33 万——很多团队"实验跑两天没差异就砍掉"，砍掉的往往是真的有效但功效不足的策略。

### 主实验（基线 + 模拟 +5% 相对提升，总样本 140 万）

| 项 | 结果 |
|---|---|
| 对照组转化率 | 19.25% |
| 实验组转化率 | 20.22% |
| 相对提升 | +5.01% |
| z 值 / p 值 | 14.34 / p < 1e-10 |
| 差值 95% 置信区间 | [0.833pp, 1.097pp] |
| SRM | χ²=0.00，p=1.0 → 分流正常 |
| 护栏（人均单量） | 0.9562 vs 0.9569，p=0.622 → 无恶化 |

结论：显著、效应量可信、护栏无伤 → **可以放量**。

### 功效不足的反例

真实 +2% 提升，但只跑 4 万样本（每组 2 万，实际需要 16.5 万）：

对照 19.29% vs 实验 19.65%，**p = 0.357，不显著**。

这策略是真的有效，只是样本不够。**"不显著"不等于"没效果"**。

### 反复窥探的代价

真实无差异，却每看一次中期结果就判断一次：

| 偷看次数 | 1 | 2 | 3 | 5 | 8 | 10 | 15 | 20 |
|---|---|---|---|---|---|---|---|---|
| 假阳性率 | 4.7% | 9.0% | 14.7% | 23.3% | 35.3% | 36.7% | 57.3% | 65.0% |

（完整曲线见 `fig2_peeking.png`，300 次模拟）

看 10 次，把 5% 的假阳性抬到近 4 成。**要么规定只看一次，要么上序贯检验（alpha spending）。**

## 5. 文件

```
03-ab-experiment/
├── 00_baseline.py        从数仓取真实基线 → baseline.json
├── ab_experiment.py      样本量 / 分流 / z 检验 / Welch / SRM / 窥探演示
├── 03_figures.py         出图
├── baseline.json         真实基线（9 天日级 UV / 购买 UV / 用户单量分布）
├── result.json           实验结果（样本量表 + 三组实验 + 窥探率）
├── peeking_curve.json    窥探次数 → 假阳性率曲线数据
├── fig1_sample_size.png  样本量 vs MDE
└── fig2_peeking.png      窥探次数 vs 假阳性率
```

只依赖标准库（正态分位数与检验均手写实现），不装 scipy 也能跑。

## 6. 复现

```bash
# 1) 取真实基线（需要先有 taobao_dw 库，见数仓项目）
set MYSQL_PWD=你的密码
python 00_baseline.py

# 2) 跑实验（只依赖标准库）
python ab_experiment.py

# 3) 出图（需要 matplotlib）
python 03_figures.py
```

仓库里已带 `baseline.json` 与 `result.json`，**不想连库也可以直接看结果**。

## 7. 可以继续做的

- 序贯检验（SPRT / alpha spending）替代"只看一次"
- CUPED 方差缩减，把样本量再压 30–50%
- 分层随机（按城市等级 / 价位分层），降低方差
- 多指标多重比较校正（Bonferroni / BH）
